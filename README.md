# Controle de Níveis de Água

## Descrição
Projeto desenvolvido em Python para simular o monitoramento do nível de água de um reservatório.

## Funcionalidades
- Armazena cinco níveis de água em uma lista.
- Utiliza a biblioteca Colorama para colorir as mensagens.
- Define as cores por meio de uma função.
- Exibe a situação do reservatório no terminal.

## Tecnologias utilizadas
- Python
- Biblioteca Colorama

## Como executar
1. Instale a biblioteca com `python -m pip install colorama`.
2. Execute o arquivo com `python IsadoraTosi_Ag11_DSI.py`.
